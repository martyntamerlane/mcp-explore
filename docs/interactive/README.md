# Interactive pages

User-requested HTML pages that visualize or interact with this codebase (architecture maps, feature dashboards, data explorers).

## Contract

- Every page is **fully self-contained**: inline CSS/JS, no external CDNs, fonts, or network calls — it must open directly from the filesystem with `file://`.
- Pages reflect the code. When a code change makes a page stale, update the page in the same change or explicitly flag the staleness to the user.
- One page per file, named for what it shows (e.g. `architecture-map.html`), listed below when added.
